# 🌐 Job Portal

A modern **Job Portal web application** where users can browse, search, and apply for jobs.  
It has a **React + TailwindCSS + DaisyUI** frontend and an **Express.js + MongoDB** backend with JWT authentication.

---

## 🚀 Live Demo

- **Client (Frontend):** [Job Portal Client](https://job-portal-c4aa6.web.app/)
- **Server (Backend API):** [Job Portal Server](https://job-portal-server-ten-pi.vercel.app/)

---

## 📌 Features

- 🔐 User authentication with **Firebase**
- 📄 Browse and search jobs
- ⭐ Save and apply for jobs
- 📝 Manage job postings
- 📊 View application status
- 🎨 Beautiful UI with **TailwindCSS + DaisyUI**
- ⚡ Responsive and optimized performance

## 🛠️ Tech Stack

## 🛠️ Technologies Used

### 🔹 Frontend:

- ⚡️ [Vite (Latest)](https://vitejs.dev/) — Fast development and build tool
- ⚛️ [React 19](https://react.dev/) — UI library
- 🌐 [React Router DOM v6](https://reactrouter.com/en/main) — Client-side routing
- 🎨 [Tailwind CSS v3](https://tailwindcss.com/) — Utility-first CSS framework
- 🧩 [DaisyUI v5](https://daisyui.com/) — Tailwind component library
- 📦 [Axios](https://axios-http.com/) — HTTP client for API calls
- 🔥 [Firebase](https://firebase.google.com/) — Authentication & Hosting

### Tools:

- 🍬 [SweetAlert2](https://sweetalert2.github.io/) — Stylish alerts & modals
- 🎞️ [Lottie-React](https://lottiefiles.com/) — Animations
- 🎯 [Motion](https://motion.dev/) — Modern animation library
- 🖼️ [Lucide-React](https://lucide.dev/icons/) — Icon set

### 🔹 Backend:

- 🔧 [Node.js](https://nodejs.org/) — JavaScript runtime
- 🚂 [Express.js](https://expressjs.com/) — Web framework
- 🗄️ [MongoDB](https://www.mongodb.com/) — NoSQL database
- 🌐 [CORS](https://developer.mozilla.org/en-US/docs/Web/HTTP/CORS) — Cross-Origin Resource Sharing
- 🔐 [JWT (jsonwebtoken)](https://github.com/auth0/node-jsonwebtoken) — Authentication & authorization
- 🔑 [dotenv](https://github.com/motdotla/dotenv) — Environment variable management
- 🍪 [cookie-parser](https://github.com/expressjs/cookie-parser) — Cookie handling middleware
