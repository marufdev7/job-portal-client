## 🛠️ Technologies Used

### Frontend:
- ⚡️ [Vite (Latest)](https://vitejs.dev/) — Fast development and build tool
- ⚛️ [React](https://reactjs.org/) — UI library
- 🌐 [React Router DOM v6](https://reactrouter.com/en/main) — Routing
- 🎨 [Tailwind CSS v3](https://tailwindcss.com/) — Utility-first CSS framework
- 🧩 [DaisyUI v4](https://daisyui.com/) — Tailwind component library

### Tools:
- 🎞️ [LottieFiles](https://lottiefiles.com/) — Animations
- 🖼️ [Icons8](https://icons8.com/) — Icons
- 🎯 [React Motion](https://github.com/chenglou/react-motion) — Animations

## 📌 Features

- Browse jobs by category, location, or keyword
- View job details and requirements
- Responsive UI with modern design
- Smooth page transitions and animations
